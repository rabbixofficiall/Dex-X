## What this build changes

See `CHANGES.md` for the running list. In short: the PC app is reduced to the
one thing it is for (connect, then the desktop), the window title bars gain
real resizing, and the reported bugs in this repo's issue list are worked
through one at a time, each with the reasoning next to the code.

## Source

The complete corresponding source is this repository. Artifacts built from it
(the launcher APK and the Windows build) are on each run of the
`Dex-X — APK + Windows EXE` workflow, built from the exact commit in the run's
title.
